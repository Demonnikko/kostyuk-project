# Инструменты проекта Dmitry Kostyuk

В данном файле перечислены и проанализированы все ключевые инструменты, обеспечивающие работу, продвижение, аналитику и мониторинг трех сайтов бренда (основной лендинг, школа магии и концерты с бронированием билетов).

---

### 1. VK Bridge API
* **Что из себя представляет:** Официальный SDK для интеграции веб-приложений с платформой ВКонтакте.
* **Какую пользу приносит:** Позволяет запускать сайт как полноценное Mini App внутри приложения ВКонтакте, использовать нативные функции соцсети (авторизация, шеринг, платежи), повышая охват аудитории.
* **Ссылка на просмотр:** [Репозиторий VK Bridge на GitHub](https://github.com/VKCOM/vk-bridge)

---

### 2. Telegram WebApp API
* **Что из себя представляет:** Набор JS-интерфейсов для встраивания веб-приложений внутрь Telegram-ботов (Telegram Web Apps / TWA).
* **Какую пользу приносит:** Дает возможность продавать билеты на концерты и общаться с AI-ассистентом прямо в Telegram, открывая сайт во встроенном WebView без перехода в стандартные браузеры.
* **Ссылка на просмотр:** [Официальная документация Telegram Web Apps](https://core.telegram.org/bots/webapps)

---

### 3. Vercel Serverless & Vercel KV
* **Что из себя представляет:** Облачная бессерверная платформа для размещения статических сайтов, Node.js API (`api/`) и быстрого Key-Value хранилища данных.
* **Какую пользу приносит:** Обеспечивает мгновенную загрузку сайтов по всему миру, берет на себя выполнение серверных функций (запросы к AI, бронирование билетов, запись мест в зале) без затрат на аренду и администрирование классических VPS-серверов.
* **Ссылка на просмотр:** [Официальный сайт Vercel](https://vercel.com)

---

### 4. PostHog (Продуктовая аналитика и Вебвизор)
* **Что из себя представляет:** Современная Open Source платформа аналитики, отслеживающая действия пользователей и записывающая видео их сессий.
* **Какую пользу приносит:** Позволяет в реальном времени смотреть видеозаписи визитов (как пользователи проходят квиз, общаются с чатом, выбирают билеты) и выявлять, на каком этапе они покидают страницу, что помогает непрерывно растить конверсию продаж.
* **Ссылка на просмотр:** [Репозиторий PostHog на GitHub](https://github.com/posthog/posthog)

---

### 5. Upptime (Автоматический мониторинг)
* **Что из себя представляет:** Бесплатный инструмент автоматического мониторинга работоспособности сайтов и API, работающий на базе GitHub Actions.
* **Какую пользу приносит:** Каждые 5 минут проверяет доступность ваших сайтов и платежных API, генерирует красивую статус-страницу и мгновенно оповещает в Telegram в случае падения серверов, сохраняя ваши деньги и репутацию.
* **Ссылка на просмотр:** [Репозиторий Upptime на GitHub](https://github.com/upptime/upptime)

---

### 6. GStack (Регламенты и стандарты ИИ-разработки)
* **Что из себя представляет:** Фреймворк и набор custom-инструкций от CEO Y Combinator Гарри Тана для жесткой координации работы ИИ-ассистентов.
* **Какую пользу приносит:** Превращает ИИ-разработчика в слаженную команду (CEO, Engineering Manager, QA Lead), исключая появление багов при обновлении кода и гарантируя стабильность работы всех сайтов бренда.
* **Ссылка на просмотр:** [Репозиторий GStack на GitHub](https://github.com/garrytan/gstack)
