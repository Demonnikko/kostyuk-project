# План реализации админки концертной кассы

## 1. Зафиксировать доменные правила тестами

- Добавить тесты переходов статусов заказа.
- Добавить тесты правил освобождения и повторной продажи места.
- Добавить контрактные проверки схемы, билетов, аудита и защиты admin API.

## 2. Обновить новую D1-схему

- Убрать исторические `order_items` из роли вечной блокировки места.
- Добавить активные назначения мест, ручные блокировки, отдельные билеты и аудит.
- Расширить заказ полями изменения статуса, причины, источника и заметки.
- Пересоздать начальную миграцию, так как запуск начинается с чистой базы.

## 3. Реализовать серверное билетное ядро

- Адаптировать удержания, создание и истечение заказа.
- Добавить административную сводку и выборки.
- Добавить безопасные переходы статусов и освобождение мест.
- Выпускать отдельные билеты при подтверждении оплаты.
- Реализовать блокировку места и сканирование билета.
- Записывать все события в аудит.

## 4. Реализовать единоличный защищённый вход

- Добавить серверную подписанную сессию.
- Добавить login/logout API и закрыть все административные API.
- Проверять same-origin для изменяющих запросов.
- Не разрешать production-вход без секретов окружения.

## 5. Собрать премиальную админку

- Создать `/admin` и экран входа.
- Создать компактную навигацию, сводку, концерты, заказы, зал, активность, сканер и журнал.
- Добавить поиск, фильтры, карточку заказа и подтверждения опасных действий.
- Добавить обновление данных каждые несколько секунд.
- Сохранить общую визуальную систему KOSTYUK PROJECT.

## 6. Проверить

- Выполнить unit/contract tests, lint и production build.
- Запустить локальную D1-миграцию и smoke-проверку API.
- Проверить `/admin` на широком и мобильном viewport.
- Проверить сценарий: удержание → заказ → оплата админом → билет → сканирование → повторный скан.
- Проверить сценарий: заказ → отмена → повторная доступность места при сохранённой истории.

## 7. Следующий слой после ядра

- Перенести промокоды, рассылки и отзывы.
- Подключить частные заявки и AI-чаты как независимые модули.
- Подключить Метрику и выгрузки.
- Настроить production-origin и перенаправление старого `/admin`.
