# Инструкция по настройке мониторинга Upptime

Поскольку Upptime работает на базе **GitHub Actions** и требует развертывания отдельного репозитория от вашего лица для бесплатного мониторинга, его невозможно напрямую встроить в текущую рабочую папку. 

Ниже приведена простая пошаговая инструкция, как настроить бесплатный мониторинг ваших сайтов и API за 3 минуты.

---

## Шаг 1: Создание репозитория из шаблона

1. Откройте официальный шаблон Upptime на GitHub: [https://github.com/upptime/upptime](https://github.com/upptime/upptime).
2. Нажмите зеленую кнопку **«Use this template»** (Использовать этот шаблон) -> **«Create a new repository»**.
3. Укажите любое имя репозитория (например, `kostyuk-status`) и сделайте его **Public** (это необходимо для бесплатной работы GitHub Pages). Нажмите кнопку **«Create repository»**.

---

## Шаг 2: Включение прав для GitHub Actions

В созданном репозитории перейдите в настройки:
1. Нажмите вкладку **Settings** (вверху справа).
2. Слева выберите **Actions** -> **General**.
3. Прокрутите страницу вниз до раздела **Workflow permissions**.
4. Выберите пункт **«Read and write permissions»** (это нужно, чтобы Upptime мог сам создавать отчеты об ошибках).
5. Нажмите кнопку **Save**.

---

## Шаг 3: Настройка мониторинга ваших сайтов

Откройте в вашем новом репозитории файл конфигурации `.upptimerc.yml` (он лежит в корне) и отредактируйте его прямо в браузере (нажав на иконку карандаша):

Замените раздел `sites:` на список ваших эндпоинтов:

```yaml
sites:
  - name: Dmitry Kostyuk Landing
    url: https://kostyuk.ru # Укажите ваш реальный домен лендинга
  - name: Magic School
    url: https://kostyuk.ru/school
  - name: Concerts & Seating
    url: https://kostyuk.ru/concerts
  - name: Booking API
    url: https://kostyuk.ru/api/seats # Проверка работоспособности системы билетов
  - name: Chat Assistant API
    url: https://kostyuk.ru/api/chat
```

Сохраните коммит (нажмите **Commit changes**).

---

## Шаг 4: Активация статус-страницы

Перейдите во вкладку **Settings** вашего репозитория:
1. Слева выберите **Pages**.
2. В разделе **Build and deployment** -> **Source** выберите **Deploy from a branch**.
3. В выпадающем списке **Branch** выберите ветку `gh-pages` (она создастся автоматически через пару минут после первого запуска) и папку `/ (root)`.
4. Нажмите **Save**.

Через несколько минут ваш мониторинг заработает, а статус-страница будет доступна по адресу `https://ваш-логин.github.io/kostyuk-status/`.

---

## Шаг 5: (Опционально) Telegram-оповещения

Чтобы сбои прилетали в ваш Telegram-чат:
1. Напишите боту `@BotFather` в Telegram и создайте нового бота, скопируйте его токен.
2. В настройках вашего репозитория Upptime перейдите в **Settings** -> **Secrets and variables** -> **Actions**.
3. Создайте новый секрет (New repository secret):
   * Имя: `NOTIFICATION_TELEGRAM_BOT_TOKEN`
   * Значение: *токен вашего бота*
4. Создайте второй секрет:
   * Имя: `NOTIFICATION_TELEGRAM_CHAT_ID`
   * Значение: *ваш персональный ID чата* (можно узнать у бота `@userinfobot`).

Теперь при любом падении сайта или API вы мгновенно получите сообщение в Telegram.
